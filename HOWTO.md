# How to

## Add a resource

1. Add it in [Resources.gd](theLudovyc/Resources/Resources.gd) (don't forget Levels)
2. Add it in [GUI.tscn](theLudovyc/GUI/GUI.tscn), in the Resources node,
3. Add it in [Recipes.gd](res://theLudovyc/Resources/Recipes.gd)

## Add a building

1. Create an AtlasTexture in the folder [atlas_textures](theLudovyc/Building/atlas_textures/)
2. Add it in [Building.gd](theLudovyc/Building/Building.gd)
3. Add it in [GUI.tscn](theLudovyc/GUI/GUI.tscn), in BuildGridContainer
4. Add it in [GridContainer.gd](res://theLudovyc/GUI/GridContainer.gd)
